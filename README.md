# cupcake-no2-biofilter-simulator

Lab 단위 식생바이오필터의 NO₂ 제거 성능과, 그 결과로 코코 코이어에 축적되는
아질산염(NO₂⁻)을 Griess 법으로 정량하는 실험의 **설계 검토용 시뮬레이터**입니다.

상명대학교 그린스마트학과 김예진 · 자기설계 실험

## 무엇인가

외부 의존성 없는 단일 HTML 파일 하나입니다(Google Fonts만 링크).

- **0-D 질량수지** — 챔버를 완전혼합조로 두고 기체상 농도와 벽면·매질의 가역
  저장고를 연립 적분합니다. 화면의 모든 정량값은 여기서 나옵니다.
- **유동 가시화** — 128×63 격자에서 2D 비압축 Navier–Stokes를 실제로 적분합니다
  (반라그랑주 이류 + Red-Black Gauss–Seidel SOR 압력투영). 다만 **정량값은 전부
  0-D 모델이 결정하고**, 농도장은 매 스텝 벌크 평균이 0-D 값에 맞도록 정규화됩니다.
  즉 이 패널은 검증된 총량의 공간 배분을 보여줄 뿐 **3D 난류 CFD 해석이 아닙니다.**
- **Griess 정량 연동** — 코이어 층이 포집한 분량에서 재방출분을 뺀 값만 NO₂⁻ 기여로
  계산해 548 nm 흡광도와 표준곡선 위치를 예측합니다.

## 한계 — 인용 전 반드시 확인

**속도상수 기본값은 문헌 앵커에 맞춘 초기값이며, 본 장비 실측으로 보정하기 전의
설계 검토용입니다.** 공챔버 시험으로 벽면 흡착·탈착을 먼저 확정하지 않으면 필터
성능이 과대평가됩니다. 보정 절차는 대시보드 하단 문서 8절에 있습니다.

식물 침착속도 `v_d`의 **종 간 상대 서열은 문헌 기반이나 절대값은 보정 대상**입니다.
흔히 인용되는 공기정화식물 순위(NASA 목록 등)는 포름알데히드·VOC 기준이며
**NO₂ 제거능의 유효한 대리지표가 아닙니다.**

## 빌드

이 저장소의 `index.html`은 생성물입니다. 원본은 별도 비공개 작업 폴더의
`no2-biofilter-sim.html`이며, `build-deploy.ps1`이 doctype·head·body를 붙여
이 파일을 만듭니다. 원본 실험계획서·챔버 도면 등은 이 저장소에 포함하지 않습니다.
